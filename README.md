# angular1

Download angular
---

    sudo apt-get install nodejs

    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
    nvm list-remote
    nvm install v20.18.1
    node -v

    npm install -g @angular/cli
    ng new angular

Run application
---
    
    ng serve -o
